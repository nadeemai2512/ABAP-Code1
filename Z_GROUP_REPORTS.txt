REPORT Z_GROUP_REPORTS.

* TO CREATE FIELDS OF SALES DOC NUMBER REFERRING TO VBELN
DATA F_SD TYPE VBELN_VA.
* TO CREATE RANGE OF INPUT FIELDS FOR VBELN
SELECT-OPTIONS S_SD FOR F_SD.
TYPES : BEGIN OF STR,
 VBELN TYPE VBELN_VA,
 POSNR TYPE POSNR_VA,
 MATNR TYPE MATNR,
 ARKTX TYPE ARKTX,
 NETWR TYPE NETWR_AP,
 KWMENG TYPE KWMENG,
 NETPR TYPE NETPR,
 END OF STR.
DATA : VBAP_IT TYPE TABLE OF STR WITH HEADER LINE.
DATA : WA_VBAP TYPE STR.
* TO GET DATA FROM THE DATA BASE CALL SUB ROUTINE
PERFORM GET_DATA.
* TO DISPLAY DATA ON THE OUTPUT SCREEN - LIST
PERFORM DISPLAY_DATA.
FORM GET_DATA.
 SELECT VBELN POSNR MATNR ARKTX NETWR KWMENG NETPR FROM VBAP
 INTO TABLE VBAP_IT WHERE VBELN IN S_SD.
 IF SY-SUBRC <> 0.
 MESSAGE 'NO RECORDS FETHED' TYPE 'E'.
 ENDIF.
* TO SORT INTERNAL TABLE
 SORT VBAP_IT.
ENDFORM.
FORM DISPLAY_DATA.
 LOOP AT VBAP_IT INTO WA_VBAP.
 AT FIRST.
 WRITE :/40 'SALES DOCUMENT DATA' COLOR 2.
 ENDAT.
 AT NEW VBELN.
 WRITE :/3 WA_VBAP-VBELN CENTERED.
 ENDAT.
 WRITE :/15 WA_VBAP-POSNR CENTERED COLOR 1 INVERSE,
 25 WA_VBAP-MATNR CENTERED COLOR 2 INVERSE,
 45 WA_VBAP-NETWR CENTERED COLOR 3 INVERSE,
 60 WA_VBAP-KWMENG CENTERED COLOR 4 INVERSE,
 75 WA_VBAP-NETPR CENTERED COLOR 5 INVERSE,
 90 WA_VBAP-ARKTX COLOR 6 INVERSE.
 AT END OF VBELN.
 SUM.
 WRITE :/45 WA_VBAP-NETWR CENTERED COLOR 3,
 60 WA_VBAP-KWMENG CENTERED COLOR 4,
 75 WA_VBAP-NETPR CENTERED COLOR 5.
 ENDAT.
 AT LAST.
 SUM.
 WRITE :/45 WA_VBAP-NETWR CENTERED COLOR 3,
 60 WA_VBAP-KWMENG CENTERED COLOR 4,
 75 WA_VBAP-NETPR CENTERED COLOR 5.
 ENDAT.
 ENDLOOP.
ENDFORM.
