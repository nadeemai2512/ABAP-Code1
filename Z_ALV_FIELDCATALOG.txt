REPORT Z_ALV_FIELDCATALOG.

* TABLE DECLARATION
TABLES: MARA, MARC.

* TYPE DECLARATION
TYPES: BEGIN OF TY_MAT,

         MATNR TYPE CHAR18,
         MTART TYPE MARA-MTART,
         MATKL TYPE MARA-MATKL,
         MEINS TYPE MARA-MEINS,
         WERKS TYPE MARC-WERKS,
         DISMM TYPE MARC-DISMM,

       END OF TY_MAT.

* INTERNAL TABLES & WORK AREA
DATA: IT_MAT  TYPE TABLE OF TY_MAT,
      WA_MAT  TYPE TY_MAT.

* FIELD CATALOG
DATA: IT_FCAT TYPE SLIS_T_FIELDCAT_ALV,
      WA_FCAT TYPE SLIS_FIELDCAT_ALV.

* LAYOUT
DATA: WA_LAYOUT TYPE SLIS_LAYOUT_ALV.

* VARIABLE
DATA: LV_MATNR TYPE MATNR.

* SELECT-OPTIONS
SELECT-OPTIONS: S_MATNR FOR LV_MATNR.

* START-OF-SELECTION
START-OF-SELECTION.

  PERFORM FETCH_DATA.
  PERFORM BUILD_FCAT.
  PERFORM DISPLAY_ALV.

* FETCH DATA FROM 2 DATABASE TABLES
FORM FETCH_DATA.

  SELECT A~MATNR
         A~MTART
         A~MATKL
         A~MEINS
         B~WERKS
         B~DISMM

    FROM MARA AS A
    INNER JOIN MARC AS B
    ON A~MATNR = B~MATNR

    INTO CORRESPONDING FIELDS OF TABLE IT_MAT

    WHERE A~MATNR IN S_MATNR.

* REMOVE LEADING ZEROS FROM MATNR
  LOOP AT IT_MAT INTO WA_MAT.

    SHIFT WA_MAT-MATNR LEFT DELETING LEADING '0'.

    MODIFY IT_MAT FROM WA_MAT.

  ENDLOOP.

ENDFORM.
* BUILD FIELD CATALOG
FORM BUILD_FCAT.

  CLEAR WA_FCAT.

  WA_FCAT-FIELDNAME = 'MATNR'.

  WA_FCAT-KEY       = 'X'.
  WA_FCAT-JUST      = 'C'.
  WA_FCAT-SELTEXT_S = 'MATNR'.
  WA_FCAT-SELTEXT_M = 'MATERIAL'.
  WA_FCAT-SELTEXT_L = 'MATERIAL NUMBER'.

* MATERIAL TYPE

* PLANT

  WA_FCAT-SELTEXT_M = 'PLANT'.

* STORAGE LOCATION

ENDFORM.
* DISPLAY ALV REPORT
FORM DISPLAY_ALV.

  WA_LAYOUT-ZEBRA = 'X'.
  WA_LAYOUT-COLWIDTH_OPTIMIZE = 'X'.

  CALL FUNCTION 'REUSE_ALV_GRID_DISPLAY'

    EXPORTING
      I_CALLBACK_PROGRAM = SY-REPID
      IS_LAYOUT          = WA_LAYOUT
      IT_FIELDCAT        = IT_FCAT
      I_GRID_TITLE       = 'ALV REPORT WITH 2 DB TABLES'

    TABLES
      T_OUTTAB           = IT_MAT

    EXCEPTIONS
      PROGRAM_ERROR      = 1
      OTHERS             = 2.

  IF SY-SUBRC <> 0.

    MESSAGE 'ERROR IN ALV DISPLAY' TYPE 'E'.

  ENDIF.

ENDFORM.
